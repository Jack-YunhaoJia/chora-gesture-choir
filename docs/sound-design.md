# CHORA 三种音色的设计与验证

更新：2026-10-01。对应源码：`src/audio/chora.dsp`、`src/audio/AudioEngine.ts`、`src/audio/presets.ts`。本页描述当前合成方法与实际编译输出，不代表真人演唱或用户听感验收已完成。

## 这次解决的问题

用户反馈麦克风已有输入，但 Vocoder 输出弱、断续或无声。核查发现，上一版为了区分音色，把 Ambient 的慢起和有限敲击直接用于麦克风载波：玻璃在持续元音下耗尽包络、趋近无声；月面在手势重新开门后仍要等待 620 ms 渐入。此次将两种模式的时间行为分开：Ambient 保留慢起合唱、衰减玻璃、快起簧片；三个 Vocoder 都以独立的 16 ms 包络开门并持续发声，由输入本身控制音节，三者通过载波频谱和玻璃瞬态保持区别。

| 预设 | Ambient | Vocoder | 质感 |
| --- | --- | --- | --- |
| 月面合唱 `moon` | 620 ms 上升包络、三层微失谐声部与流动元音共振峰，保持时持续发声 | 16 ms 开门的持续漂移合唱载波；12 ms 音节攻击 / 110 ms 释放 | 增加漂移、元音共振与上方谐波 |
| 玻璃花园 `glass` | 基音、八度和 2.756 / 5.404 倍非整数钟琴泛音，各自有限衰减，持续音底层为零 | 持续的明亮谐波与八度载波，叠加换和弦、重奏及实际输入音节触发的敲击；2 ms 分析攻击 / 26 ms 释放 | 增加八度谐波与敲击金属感；不切断持续元音 |
| 暖流簧风 `warm` | 9 ms 进入，脉冲簧片、八度管风琴层和轻微饱和，稳定持续 | 16 ms 开门的稳定脉冲载波；4 ms 音节攻击 / 46 ms 释放 | 改脉冲宽度、八度厚度和饱和 |

默认 `brightness / space / texture` 分别为月面 `0.48 / 0.74 / 0.68`，玻璃 `0.78 / 0.27 / 0.62`，暖流 `0.56 / 0.10 / 0.64`。三者共用一个立体声扩散网络，但近反射与送入比例有区别，暖流保持靠前。四声部和所选和弦不变。名称描述设计方向，未使用真人或真实乐器录音。

## 演奏控制

- **音色身份**：`soundPreset: 'moon' | 'glass' | 'warm'` 选择独立声音路径，旋钮不会抹掉身份。
- **玻璃重奏**：换音高、重新开声部、换预设、换模式或明确重按和弦触发一次；普通手势跟踪、力度或滤色变化不会重新起音。Ambient 长按会安静下来，需重奏或换和弦再响。
- **Vocoder 玻璃音节**：比较实际输入的快速包络与近期平均值，在明显由弱变强时重触发；另有低电平门槛。持续元音保持载波发声，也不会自动形成循环敲击。音节检测只给已有持续载波增加瞬态，低电平门槛不再决定有没有声音；识别依据是幅度上升而非文字或音素。真人连唱、辅音及噪声环境仍需验证。
- **Vocoder 输入**：16 个频段把输入包络施加到固定和弦载波上，没有干声直通，不保留歌手原音色，不自动猜和弦。真实麦克风路径没有额外合成元音；静音输入不发声。免设备试听明确使用合成元音。
- **右腕滤色**：独立 `wristTone=0..1`，默认 `0.5` 是严格旁通；暗侧低通跟随最高声部，亮侧增强泛音并补偿增益。预设底色、音高、声部和重奏状态不变。
- **切换与静音**：预设和模式以 120 ms 时间常数淡化，频率平滑 18 ms 且首次直接从所选音高开始。`active=false` 关闭声部，并把混响之后的总音量以 40 ms 时间常数归零。后级高通和 `0.9 × tanh` 保持数值输出有界。

## 可复验试听和检查

`npm run audio:compile` 真实编译 Faust，生成 WASM、控制元数据、静态 AudioWorklet、六段 WAV 和 `public/audio/demos/report.json`。六段 48 kHz / 16-bit / stereo 试听固定相同音区、力度、明亮度 `0.58`、空间 `0.55`、质感 `0.5`、右腕 `0.5` 和主音量，时长 11.8 秒，和弦为 Cmaj7 → Am7 → Fmaj7 → G7，10.16 秒统一静音。文件没有逐条响度归一化；短音的长期 RMS 本来就会小于持续音，不应把它当成需要补足的音量缺陷。

Vocoder 三条用同一份确定性的 147 Hz 合成元音，来源另存 `source-synthetic-vowel.wav`；不是人声录音或唱词清晰度验收。固定四秒输出统计、起音/持音包络、干声与强制 `space=0.55` 的长按检查、谱能量距离与腕部检查分开报告。波形不同比值只能证明不同，不能证明好听；谱质心也不单独作为乐器身份的判断。

腕部测试在有效起音窗口测量频谱和实际基频，避免把玻璃衰减后的静音当作持续音进行 FFT。中立与独立编译的腕部旁通 DSP 逐样本比对；动态回中后先重奏再比较同一有效窗口。全声部关闭、Vocoder 静音输入和统一静音均需通过。

边界检查覆盖 44.1 / 48 / 96 kHz、两模式、三预设、腕部两个端点、低高音区、明亮度/质感/空间两端，共 144 组实际 WASM 渲染。另测 Ambient 玻璃衰减、三个 Vocoder 的持续元音、玻璃瞬态重奏、输入停止后释放、预设/模式切换。弱输入固定合成元音覆盖 RMS 0.003 / 0.01 / 0.03，各自测试 0 dB 与模拟 +12 dB 输入增益；同时检查每个 100 ms 窗口，防止整段平均值掩盖断续。200 ms 手势中断检查同时关闭声部及总音量，再与相同相位的不中断输出比对恢复速度。输入增益在离线仅是信号缩放，不能替代浏览器 GainNode 与设备验证。浏览器正式 AudioWorklet、真人手势/演唱、艺术偏好与端到端延迟应另记到 `VALIDATION.md`。

## 当前测量结果

本轮真实 Faust 2.89.2 编译产生 81,502 字节 WASM。以下数字来自该编译产物；最终完整报告保存源码与 WASM SHA256，以便核对发布资源。共同控制值下，Vocoder 三种长期频谱质心约为月面 606 Hz、玻璃 925 Hz、暖流 705 Hz；玻璃保持明亮谐波，月面保留漂移，暖流保留脉冲结构。

| 模式 / 预设 | 起音 / 音体 RMS 比 | 晚段 RMS | 时间行为 |
| --- | ---: | ---: | --- |
| Ambient / 月面 | 0.145 | 0.1191 | 缓慢进入，持续 |
| Ambient / 玻璃 | 2.283 | 1.1786e-12 | 敲击后完全衰减 |
| Ambient / 暖流 | 0.919 | 0.083521 | 快速进入，持续 |
| Vocoder / 月面 | 0.974 | 0.15891 | 快速进入，持续 |
| Vocoder / 玻璃 | 0.848 | 0.16168 | 快速进入，持续 |
| Vocoder / 暖流 | 0.866 | 0.18134 | 快速进入，持续 |

表格采用相同 `space=0.55`，在 0.4 秒开声部；起音比是开门后 15–75 ms RMS / 开门后 350–650 ms RMS，晚段是开门后 4.1–5.1 秒。Ambient 玻璃仍按原设计完全衰减；Vocoder 玻璃持续元音已保留非零声音。玻璃同一元音 3–6 秒干声 RMS 为 0.17126，明确重奏后波形归一化差异 0.4927：重奏增加瞬态，不再决定持续人声的有无。

弱输入测试关闭空间，用固定合成元音、默认输出音量与力度。以下为 3–5 秒输出 RMS：

| 原始输入 RMS | 月面 0 / +12 dB | 玻璃 0 / +12 dB | 暖流 0 / +12 dB |
| ---: | ---: | ---: | ---: |
| 0.003 | 0.00508 / 0.02017 | 0.00583 / 0.02316 | 0.00643 / 0.02552 |
| 0.01 | 0.01690 / 0.06554 | 0.01941 / 0.07497 | 0.02139 / 0.08258 |
| 0.03 | 0.04998 / 0.16467 | 0.05727 / 0.18509 | 0.06310 / 0.20300 |

九种弱输入组合在逐段 100 ms 窗口均保持发声；模拟 +12 dB 输入提升后，输出增长约 3.22–3.97 倍，强信号受现有饱和级约束。零输入仍由分析包络归零，没有麦克风干声直通。这里的增益是离线缩放，浏览器与真人设备结果须另行验收。

200 ms 手势中断同时关声部与总音量。重新开门后的 80–200 ms 输出相对同相位不中断基线，月面为 95.8%、玻璃 86.7%、暖流 96.1%；200–400 ms 为 99.9%、88.2%、99.9%。中断末段输出均低于基线 0.031%。玻璃重入带敲击，最大相邻采样差 0.2234；不中断亮载波本身为 0.2019，因此新重入测试同时约束峰值、相对恢复幅度，以及相对基线的采样变化（最多 1.2 倍，保留 0.22 下限）。这个检查不能替代听辨瞬态或点击声。

完整编译脚本最终通过：144 组边界全部有限非零，最高峰 0.869755；六组合腕部中立与独立旁通逐样本一致，实际基频最大变化 0.0626 音分，回中残差最大 0.000439。全声部关闭与 Vocoder 无输入均为零；统一静音残余最大 4.38e-12，输入停止后的最大残余 9.71e-11。三个 Ambient 试听文件与修复前逐字节一致，三个 Vocoder 试听更新。完整源码/产物摘要和各项原始测量在报告中。
