# CHORA 三种音色的设计与验证

更新：2026-09-29。对应源码：`src/audio/chora.dsp`、`src/audio/AudioEngine.ts`、`src/audio/presets.ts`。本页描述当前合成方法与实际编译输出，不代表真人演唱或用户听感验收已完成。

## 这次解决的问题

用户再次反馈三种声音同质化严重。上一版虽然使用不同振荡器，玻璃敲击之后仍保留不衰减的合成底层；Vocoder 三者也都是持续载波套相似的音节包络。因此只改频谱和默认混响不足以解决持手时趋同的问题。本版直接分开发声与时间行为：月面缓慢浮现并持续漂移；玻璃每次敲击后完全衰减；暖流直接进入稳定簧片与八度管风琴。空间和明亮度的默认值也区分开，但同条件验证把它们固定为相同数值。

| 预设 | Ambient | Vocoder | 质感 |
| --- | --- | --- | --- |
| 月面合唱 `moon` | 620 ms 上升包络、三层微失谐声部与流动元音共振峰，保持时持续发声 | 同样慢起与漂移的合唱载波；36 ms 音节攻击 / 210 ms 释放 | 增加漂移、元音共振与上方谐波 |
| 玻璃花园 `glass` | 基音、八度和 2.756 / 5.404 倍非整数钟琴泛音，各自有限衰减，持续音底层为零 | 由换和弦、重奏及实际输入音节上升触发同类短敲击；2 ms 音节攻击 / 26 ms 释放 | 调金属泛音强度及各层余韵，始终不恢复持续底层 |
| 暖流簧风 `warm` | 9 ms 进入，脉冲簧片、八度管风琴层和轻微饱和，稳定持续 | 稳定脉冲载波与紧凑音节；4 ms 攻击 / 46 ms 释放 | 改脉冲宽度、八度厚度和饱和 |

默认 `brightness / space / texture` 分别为月面 `0.48 / 0.74 / 0.68`，玻璃 `0.78 / 0.27 / 0.62`，暖流 `0.56 / 0.10 / 0.64`。三者共用一个立体声扩散网络，但近反射与送入比例有区别，暖流保持靠前。四声部和所选和弦不变。名称描述设计方向，未使用真人或真实乐器录音。

## 演奏控制

- **音色身份**：`soundPreset: 'moon' | 'glass' | 'warm'` 选择独立声音路径，旋钮不会抹掉身份。
- **玻璃重奏**：换音高、重新开声部、换预设、换模式或明确重按和弦触发一次；普通手势跟踪、力度或滤色变化不会重新起音。Ambient 长按会安静下来，需重奏或换和弦再响。
- **Vocoder 玻璃音节**：比较实际输入的快速包络与近期平均值，在明显由弱变强时重触发；另有低电平门槛。持续元音不会自动形成循环敲击。识别依据是幅度上升而非文字或音素，真人连唱、辅音及噪声环境仍需验证。
- **Vocoder 输入**：16 个频段把输入包络施加到固定和弦载波上，没有干声直通，不保留歌手原音色，不自动猜和弦。真实麦克风路径没有额外合成元音；静音输入不发声。免设备试听明确使用合成元音。
- **右腕滤色**：独立 `wristTone=0..1`，默认 `0.5` 是严格旁通；暗侧低通跟随最高声部，亮侧增强泛音并补偿增益。预设底色、音高、声部和重奏状态不变。
- **切换与静音**：预设和模式以 120 ms 时间常数淡化，频率平滑 18 ms 且首次直接从所选音高开始。`active=false` 关闭声部，并把混响之后的总音量以 40 ms 时间常数归零。后级高通和 `0.9 × tanh` 保持数值输出有界。

## 可复验试听和检查

`npm run audio:compile` 真实编译 Faust，生成 WASM、控制元数据、静态 AudioWorklet、六段 WAV 和 `public/audio/demos/report.json`。六段 48 kHz / 16-bit / stereo 试听固定相同音区、力度、明亮度 `0.58`、空间 `0.55`、质感 `0.5`、右腕 `0.5` 和主音量，时长 11.8 秒，和弦为 Cmaj7 → Am7 → Fmaj7 → G7，10.16 秒统一静音。文件没有逐条响度归一化；短音的长期 RMS 本来就会小于持续音，不应把它当成需要补足的音量缺陷。

Vocoder 三条用同一份确定性的 147 Hz 合成元音，来源另存 `source-synthetic-vowel.wav`；不是人声录音或唱词清晰度验收。固定四秒输出统计、起音/持音包络、干声与强制 `space=0.55` 的长按检查、谱能量距离与腕部检查分开报告。波形不同比值只能证明不同，不能证明好听；谱质心也不单独作为乐器身份的判断。

腕部测试在有效起音窗口测量频谱和实际基频，避免把玻璃衰减后的静音当作持续音进行 FFT。中立与独立编译的腕部旁通 DSP 逐样本比对；动态回中后先重奏再比较同一有效窗口。全声部关闭、Vocoder 静音输入和统一静音均需通过。

边界检查覆盖 44.1 / 48 / 96 kHz、两模式、三预设、腕部两个端点、低高音区、明亮度/质感/空间两端，共 144 组实际 WASM 渲染。另测持续元音后玻璃衰减、新音节重新敲击、输入停止后释放、预设/模式切换及明确重奏。浏览器正式 AudioWorklet、真人手势/演唱、艺术偏好与端到端延迟应另记到 `VALIDATION.md`。

## 当前测量结果

本轮实际编译 Faust 2.89.2，WASM 77,943 字节，全部离线检查通过。下表采用共同 `space=0.55`、其余控制亦相同，在 0.4 秒开声部后测量。起音比是开门后 15–75 ms RMS / 开门后 350–650 ms RMS；晚段是开门后 4.1–5.1 秒。

| 模式 / 预设 | 起音 / 音体 RMS 比 | 晚段 RMS | 时间行为 |
| --- | ---: | ---: | --- |
| Ambient / 月面 | 0.145 | 0.11910 | 缓慢进入，持续 |
| Ambient / 玻璃 | 2.283 | 1.18e−12 | 直接敲击，完全衰减 |
| Ambient / 暖流 | 0.919 | 0.08352 | 直接起音，持续 |
| Vocoder / 月面 | 0.153 | 0.15977 | 人声慢起、持续 |
| Vocoder / 玻璃 | 2.741 | 1.06e−12 | 音节敲击后衰减 |
| Vocoder / 暖流 | 0.929 | 0.18135 | 紧凑人声、持续 |

干声的 Ambient 起音比分别为 0.161 / 2.342 / 0.923，玻璃晚段精确为零。Vocoder 的持续元音测试保留变化共振峰但取消周期幅度起伏；真实输入驱动的新音节测试则恢复周期幅度上升。玻璃在无和弦重奏消息时，新音节的 3–6 秒 RMS 为 0.13744，而持续元音对应窗口为零。说明敲击来自输入变化而非自动播放的循环；这不是对真人音节检测准确率的评价。

四秒持续渲染、跳过前 0.5 秒的 RMS / 功率谱质心分别为 Ambient 月面 0.07731 / 255 Hz、玻璃 0.01536 / 188 Hz、暖流 0.08338 / 458 Hz，Vocoder 月面 0.07426 / 602 Hz、玻璃 0.11514 / 558 Hz、暖流 0.08211 / 705 Hz。玻璃高频先消失，晚窗口质心不能代表敲击头；有效起音窗口的玻璃中立质心为 329 Hz（Ambient）和 507 Hz（Vocoder）。四个频带能量占比距离的各对最小值为 Ambient 0.262、Vocoder 0.209，波形独立 RMS 归一化后的差异为 1.018–1.751。持续音和短音不强行匹配整段 RMS。

| 模式 / 预设 | 右腕暗 / 中 / 亮质心（Hz） |
| --- | ---: |
| Ambient / 月面 | 181 / 200 / 237 |
| Ambient / 玻璃 | 234 / 329 / 382 |
| Ambient / 暖流 | 197 / 454 / 713 |
| Vocoder / 月面 | 273 / 568 / 681 |
| Vocoder / 玻璃 | 332 / 507 / 551 |
| Vocoder / 暖流 | 233 / 662 / 870 |

频谱采用起音后 0.02 / 0.10 / 0.21 / 0.39 / 0.63 秒的 8192 点 Hann 窗；实际基频采用 0.16 秒起的 16384 点 Hann 窗插值。六组中立与腕部旁通逐样本完全一致，端点实际基频最大变化 0.0377 音分；回中并重奏后的归一化残差最大 0.000440。固定样本腕部相对中立 RMS 变化 −3.32 至 +1.87 dB。

144 组边界输出均有限且非零，最高峰 0.876997。所有声部关闭和 Vocoder 无输入，从第一采样起 RMS 为零；统一静音后的最大残余 4.38e−12，输入一秒后停止、4–5 秒测得最大残余 8.10e−9。预设 / 模式 / 重奏序列最大相邻采样差 0.09781，明确重奏改变玻璃输出。数值界限不替代真人听感、唱词清晰度、长时设备表现或实际声压验收。
