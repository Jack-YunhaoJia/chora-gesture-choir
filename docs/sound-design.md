# CHORA 三种音色的设计与验证

更新：2026-09-29。对应源码：`src/audio/chora.dsp`、`src/audio/AudioEngine.ts`、`src/audio/presets.ts`。本页描述当前合成方法与可复验结果，不代表真人演唱或听感评审已经完成。

## 问题与改动

用户反馈三个预设听起来接近。核查旧界面发现，预设只有 `[space, brightness]` 两个数值，没有传入 `soundPreset` 或 `texture`；手势更新又直接覆盖明亮度，因此在演奏中连部分预设差别也会被抹掉。同一个合成器调亮、加混响，不能稳定提供三种乐器的身份。当前为三个预设指定独立振荡器/载波、起音、谐波与空间反射，并通过 `soundPreset` 传到 Faust 的 `preset` 参数。默认旋钮值只是各乐器的起点；即使旋钮完全相同，乐器仍然不同。界面保留预设明亮度作为基准，右手腕改用独立的 `wristTone` 控制滤色。先前附加 ±0.25 明亮度时，大部分截止频率仍在 2–8 kHz；常用和弦能量集中在更低频段，因此虽然数值变化，音色差异容易很弱。

| 预设 | Ambient 发声结构 | Vocoder 发声结构 | 质感旋钮 |
| --- | --- | --- | --- |
| 月面合唱 `moon` | 基音主导的加法音色，缓慢进入，轻微失谐与移动共振峰 | 平滑锯齿与正弦载波，中频偏重，17 ms 分析攻击 / 130 ms 释放 | Ambient 调共振峰、漂移与上方谐波；Vocoder 调载波漂移 |
| 玻璃花园 `glass` | FM 敲击与短暂非整数泛音；敲击衰减后保留稳定和弦 | FM 与少量锯齿载波，3 ms 分析攻击 / 38 ms 释放 | 调 FM 调制深度；Ambient 同时调敲击衰减与金属泛音 |
| 暖流簧风 `warm` | 锯齿、脉冲与基音混合，软饱和，直接起音与轻微呼吸起伏 | 脉冲 / 锯齿载波，低中频偏重，7 ms 分析攻击 / 69 ms 释放 | 调脉冲宽度、谐波配比与饱和程度 |

两种模式沿用四个独立声部。Vocoder 的 16 个频段把输入包络加到和弦载波上，音高来自所选和弦；它不进行保留歌手原音色的移调，也不从歌声自动推断和弦。上述合唱、玻璃、簧片名称描述设计方向，不表示使用了真实乐器录音或已证明唱词可懂度。

## 演奏控制

- **音色身份**：`soundPreset: 'moon' | 'glass' | 'warm'`；在两个模式中都选择真实不同的 DSP 路径。
- **质感**：`texture: 0..1`；含义随音色变化，如上表。明亮度控制各乐器滤波，空间控制短反射与共同扩散网络，力度与总音量控制最后输出。
- **右腕滤色**：`wristTone: 0..1`，可省略，默认 `0.5`；中立严格旁通，明亮度基准不变。暗侧把 Q=0.9 的共振低通扫到最高已启用声部基频的 1.1 倍，亮侧用一阶高频架增强泛音，并做固定增益补偿；音区改变时滤色转折随声部移动，最高转折限制在 9 kHz。右腕控制不重触发起音、不改音高或和弦性质。滤色先于空间效果，两模式和三个预设全部适用。
- **重奏**：换音高、重开声部或更换音色触发玻璃起音；`AudioEngine.retrigger()` 可在相同和弦上再次敲击。连续手势帧不发送重奏，避免一帧一帧重新起音。
- **切换**：预设与 Ambient / Vocoder 以 120 ms 时间常数交叉淡化；频率以 18 ms 平滑变化，首次启动直接从所选频率初始化，避免从 0 Hz 滑入。旋钮平滑在 DSP 内完成；右腕参数为 65 ms、音区参考为 80 ms 时间常数。
- **静音**：`active=false` 同时关闭声部并把混响之后的总音量淡至零（40 ms 时间常数）。麦克风没有直通监听；关闭合成元音后，安静输入不产生持续载波。

三种预设使用同一套后级高通与软饱和（上界 0.9），浏览器另有动态压缩器。这是数值保护，不是对扬声器、耳机声压或所有外部输入的保证。演奏仍应从适当设备音量开始。

## 可复验对比

执行 `npm run audio:compile` 会真实编译 Faust 2.89.2，生成 `public/audio/chora.wasm`、元数据与静态 AudioWorklet，并自动渲染六个试听文件和机器可读报告：

- `public/audio/demos/ambient-{moon,glass,warm}.wav`
- `public/audio/demos/vocoder-{moon,glass,warm}.wav`
- `public/audio/demos/source-synthetic-vowel.wav`
- `public/audio/demos/report.json`

六个 48 kHz / 16-bit / stereo 试听固定 `wristTone=0.5`，都长 11.8 秒，使用 Cmaj7 → Am7 → Fmaj7 → G7，同一音区、力度、明亮度、质感、空间与总音量，10.16 秒统一静音。没有对每条音频分别归一化，也没有真人声音。Vocoder 三条使用完全相同的 147 Hz 基频、确定性变化的合成元音输入。它适合比较音色处理差异，不适合评判真实唱词、辅音或呼吸处理。

以下测量来自另一组四秒持续 Cmaj7 渲染，跳过前 0.5 秒统计幅度；频谱用五段 8192 点 Hann 窗累计功率，质心为功率加权频率。这里的 RMS 不是感知响度或 LUFS。

| 模式 | 月面合唱 RMS / 质心 | 玻璃花园 RMS / 质心 | 暖流簧风 RMS / 质心 |
| --- | ---: | ---: | ---: |
| Ambient | 0.08048 / 210 Hz | 0.07463 / 295 Hz | 0.07437 / 381 Hz |
| Vocoder | 0.06864 / 636 Hz | 0.06849 / 620 Hz | 0.06250 / 545 Hz |

固定输入下，三种 Ambient 的 RMS 最大差约 0.69 dB，Vocoder 约 0.82 dB。四个频带（35–250、250–1000、1000–4000、4000–12000 Hz）的能量占比距离：Ambient 各对为 0.109–0.582，Vocoder 为 0.298–0.809。Vocoder 的月面与玻璃质心接近，但能量分布与载波波形明显不同，因此不把单一质心值当成音色身份判断。

为单独检查起音，在控制稳定后开门，关闭空间处理，取开门后 15–75 ms 相对于 0.7–1.0 秒音体的 RMS 比值：月面 **0.212**、玻璃 **1.484**、暖流 **0.639**。月面渐入、玻璃敲击的瞬态更强、暖流较直接。玻璃在开门后 3.2–3.5 秒仍有 RMS **0.0670** 的持续音，长时间保持和弦不会变成无声。

质感从 0 调到 1 后，对波形分别除以自身 RMS 再计算差异，Ambient 三种为 **0.466 / 0.508 / 0.620**，Vocoder 为 **1.476 / 0.950 / 0.729**。该指标证明旋钮改变输出，不等同于变化更好听。

## 右腕滤色的独立验证

同一合成输入、和弦和旋钮值下，关闭空间处理，分别渲染 `wristTone=0 / 0.5 / 1`。以下为四秒干信号、相同五段窗口测得的功率质心，不对每个结果单独归一化：

| 模式 / 预设 | 暗侧 / 中立 / 亮侧质心（Hz） | 暗侧 / 亮侧相对中立 RMS（dB） |
| --- | ---: | ---: |
| Ambient / 月面 | 183 / 206 / 249 | +1.37 / −1.07 |
| Ambient / 玻璃 | 207 / 290 / 359 | +0.33 / +0.07 |
| Ambient / 暖流 | 200 / 378 / 554 | +0.12 / +0.35 |
| Vocoder / 月面 | 231 / 627 / 810 | −1.59 / +1.40 |
| Vocoder / 玻璃 | 304 / 608 / 674 | −3.33 / +2.12 |
| Vocoder / 暖流 | 212 / 542 / 761 | −0.45 / +0.85 |

六组从暗到亮的 1–12 kHz 能量占比提升 **215–1511 倍**，同时每组质心按暗→中→亮上升。暗侧高频已很低，所以占比的倍数不能当作感知音量或“听起来强多少”的尺度。固定补偿让当前样本总 RMS 变化保持在 −3.33 至 +2.12 dB 内；这不是对任何外部人声的自动响度归一化。

脚本另编译一份只旁通腕部滤色级的 DSP；六组中立输出与它逐采样相同，更新前后的六段中立试听统计也完全一致。单独渲染 220 Hz 声部，以 65536 点 Hann 窗 FFT 插值检查真实输出基频，腕部端点相对中立最大变化 **0.0132 音分**。动态暗→亮→中立后，最后窗口的归一化波形残差不超过 **0.00072**（单精度平滑的微小渐近残余），序列最大相邻采样差 **0.124**。

144 组边界渲染覆盖两模式、三预设、腕部两个端点、MIDI 36 / 81 起点的低高音区、明亮度/质感/空间的两个极值以及 44.1 / 48 / 96 kHz。输出全部有限、非零，最大峰值 **0.855**。腕部端点下关闭全部声部、Vocoder 无输入，均为零输出。上述是实际编译 WASM 的离线检查，音频引擎另外验证独立参数路径、默认中立、范围约束、无重奏和不改和弦。

## 自动检查覆盖与限制

- 编译的所有控制路径必须存在；缺失时渲染脚本立即失败。`tests/audio-engine.test.ts` 对引擎实际发送的路径与编译元数据做匹配，并检查预设身份、模式切换时音高/声部保持、明确重奏、静音与加载快照。
- 三种 Vocoder 从第一采样起在静音输入下输出为零；六种组合从启动起关闭全部声部输出为零。统一静音后 11 秒至结束 RMS 最大约 `1.97e-13`。
- 合成输入一秒后停止，四至五秒的残留 RMS 最大约 `7.25e-11`。此项验证输入停止后的衰减，不是假定混响在停止输入瞬间消失。
- 所有被测输出有限；中立腕部的上下限旋钮组合与更高音区测试最大峰值为 **0.818**，加入腕部端点的边界渲染最大峰值为 **0.855**。预设 / 模式切换 / 重奏的混合序列最大相邻采样差为 **0.0983**，未超过脚本阈值；此项不能取代耳机排查咔哒声。
- 44.1、48、96 kHz 均实际实例化 WASM 并产生有限非零输出。非 48 kHz 的检查覆盖两个模式与全部预设，Vocoder 使用内置合成元音。
- 本次离线检查不经过浏览器压缩器。正式构建 AudioWorklet 的浏览器检查、真实设备表现、主观音色偏好、实际唱词清晰度、延迟及长时间演奏应与离线结果分别记录在 `VALIDATION.md`。

试听音频提供可审阅的结果，数值证明三个音色的发声机制和输出有区别；“精致”“适合演唱伴奏”仍需要用户试听与真人排练确认。
