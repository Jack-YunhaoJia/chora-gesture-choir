## 本次核实到的映射

以 [完整和弦指南](https://synthgesture.com/blog/how-to-use-gesture-synth-chords)、[关键点到音乐的官方说明](https://synthgesture.com/blog/how-gesture-synth-turns-hand-landmarks-into-music) 与公开网页客户端构建互相核对，范围限于 Gesture Chords。

- 左手：普通 1–5 指选择 I–V；食指＋小指为 VI；再加拇指为 VII。参考实现对普通 1–5 接受任意手指计数。
- 左腕：切换大／小和弦性质；可通过设置固定。其“小模式”不是自动小调顺阶和声。
- 右手：非拇指 1–4 指依次选择开放三和弦、第一转位、大七／小七、属七／减七；拇指另将全部音降低一个八度。
- 右手高度控制音量，倾斜控制滤波。配器改变音列，不是另一个音色合成器，也没有自动生成琶音的证据。
- 官方支持固定大／小性质和固定配器的入门预设，另有四轨循环和录音。循环能让演奏者铺完和声后腾出双手，但本次尚未在 CHORA 实现。

详细音列、稳定阈值、来源边界与交互分析见 [SynthGesture 交互分析](synthgesture-interaction-analysis.md)。客户端证据是本次公开构建的静态检查；不是复制第三方实现，亦不等同于真人识别或端到端延迟验收。

## CHORA 的实现与有意差异

本次将 VI/VII 改为已确认的食指＋小指／再加拇指，取代原先自行设计的 🤙 与 L。I–V 仍要求界面所示的完整指型，以减少随意计数带来的误选，不能称为逐项复刻参考工具。

按用户最新要求，当前界面默认开启左腕减／小／大／增四区（这是 CHORA 的扩展），右腕独立扫音色；提供明显开关与实时指示。默认大三和弦；顺阶伴奏及七和弦仍可选择，四种右手配器与低八度仍为可选。自由模式使用相同七个根音类别，VII 仍在主音上方，参考实现则放在下方。四种和弦性质切换来自左腕，配器与八度来自右手；是否采用这些已确认参数由界面设置决定。

角度按视频实际宽高比校正，指画面内侧倾，不是前后翻掌；右腕约±30°映射独立0–1音色参数，与预设明亮度分开，回中保持原色。左腕回中恢复大和弦。

稳定策略由 CHORA 独立设计：完整左手指型确认 140 ms；左腕按 −30°、−10°、+25° 划分四区，每个分界有约 3° 防抖缓冲并需 140 ms 确认；右手配器＋八度作为同一候选确认 140 ms。左腕和连续表情另受 85 ms 时间常数平滑影响，所以这些数字不能当作端到端延迟。根音、模式、右手配器独立确认，避免不相关维度的抖动阻塞全部演奏；同时换多个维度可能在不同帧生效，尚不承诺原子换和弦。

任一角色丢失、任一手握拳、右手只伸拇指均立即请求静音，清空接受状态，重新摆手后须再次稳定。此规则在固定配器时仍成立；参考站固定配器时右手握拳不一定静音。Ambient 保持自然歌声独立、摄像头即可演奏；Vocoder 为可切换的独立声音模式。没有复用第三方代码、音乐录音或品牌素材。
