# CHORA · 掌中的合唱团

一件用双手指挥和弦的浏览器声音作品。参考 SynthGesture 的演唱伴奏方式：默认左手指型选根音、手腕侧倾切减／小／大／增和弦，右手抬高管力度、侧倾扫音色。Ambient 合成器为自然演唱铺底；Vocoder 可把人声频谱融入和弦。两种模式可在演奏中切换。

**在线体验：[打开 CHORA](https://jack-yunhaojia.github.io/chora-gesture-choir/)** · [公开源码](https://github.com/Jack-YunhaoJia/chora-gesture-choir)

## 开始体验

安装 Node.js 22 或更新版本，在本目录运行：

```bash
npm ci
npm run assets
npm run dev
```

打开终端给出的 `http://127.0.0.1:5173`。建议使用桌面版 Chrome / Edge 并佩戴耳机。

- **先试听探索**：不申请设备权限，直接使用鼠标与键盘。Vocoder 使用明确标注的合成元音调制信号。
- **开启摄像头**：点击舞台中央或顶部的绿色按钮。摄像头与声音独立启动，预览立即显示，手势模型另行加载。Vocoder 的麦克风由麦克风按钮单独连接。
- **仅用麦克风 + 手动和弦**：先试听，再点击人声输入旁的麦克风按钮，然后切换 Vocoder。

`npm run assets` 首次联网下载固定版本的 MediaPipe 模型，复制识别运行库，并在本机编译 Faust。当前交付目录已具备这些资源；重新安装或复制仅源码时应再次执行此命令。网页打开后，声音处理和手势推理均在浏览器本地完成，不上传或录制摄像头和麦克风内容。字体可从 Google Fonts 加载，无法联网时使用系统字体。

## 摄像头入口

舞台中央和右上角的「开启摄像头」均可启动；底部「开启摄像头并演奏」作用相同。「切换为共振场 / 显示摄像头画面」只控制视图。连接中会明确显示等待授权、预览已开启或模型加载；可随时取消。

摄像头不等待音频恢复。声音未被浏览器启用时，镜头仍可工作，点击「启用声音」即可重试。正常演奏切后台会停止设备；授权/加载期间允许20秒短暂后台，返回恢复，持续离开则关闭。

## 如何演奏

| 动作 | 效果 |
| --- | --- |
| 左手食指 | I |
| 左手食指＋中指 | ii |
| 左手再加无名指 | iii |
| 左手四指展开、拇指收起 | IV |
| 左手五指张开 | V |
| 左手食指＋小指（🤘） | vi |
| 左手食指＋小指＋拇指（🤟） | vii |
| 右手抬高 / 在画面中左右侧倾 | 增加力度 / 独立音色扫动（左暗、右亮，回中原色） |
| 启用右手配器后，非拇指 1 / 2 / 3 / 4 指 | 开放三和弦 / 第一转位 / 七和弦 / 属七或减七 |
| 启用右手配器后，展开拇指 | 全部声部降低一个八度 |
| 左腕在画面中左右侧倾（默认启用） | 由左到右：减、小、大、增；回中为大和弦 |
| 任一只手握拳或离开镜头 | 静音 |
| 1–7 / A、S、D、F | 手动选和弦 / 开关四声部 |
| 按住舞台拖动 / 拖动右腕音色滑杆 | 试听时左右选和弦、上下扫音色 / 单独对比暗亮 |
| 空格 / Esc | 静音 / 结束演奏并释放设备 |

“和弦手 / 表情手”的默认分工是左 / 右，可点击按钮交换。完整指型保持140ms才确认；右手配器和八度整组确认、左腕性质独立确认，每个分界带约3°缓冲；换形过程最多保留上一和弦250ms，握拳、右手只伸拇指或失去任何角色立即请求静音。检测数组顺序不决定角色。默认 C 参考音、自由左腕四区、三和弦，初始大和弦。若选择“顺阶伴奏”，C大调七和弦为 Cmaj7、Dm7、Em7、Fmaj7、G7、Am7、Bm7b5。三和弦模式为 C、Dm、Em、F、G、Am、Bdim，第四声部改为高八度根音。

镜头画面是主要演奏舞台，也可以切换粒子共振场或全屏。声音不会从歌声自动推断和弦；它仍由手势选择。第一版不包含保留原音色的人声 pitch-shifter。

参考视频作者明确说明使用 [SynthGesture](https://synthgesture.com/)。[完整指南](https://synthgesture.com/blog/how-to-use-gesture-synth-chords)与公开客户端已核实七级指型，以及左腕大/小、右手配器/八度的规则。本版已修正先前自拟的六、七级；I–V 仍要求图示完整指型，与参考按任意指数组合计数有区别。详细来源和效率分析见 [交互分析](docs/synthgesture-interaction-analysis.md)。

**左腕四区切减／小／大／增**默认开启，舞台下方有独立开关、角度条与已确认和弦性质。关闭会固定当前和弦性质；选择**顺阶伴奏**则按调性决定性质。自由模式中：C 参考音的 II 可得到 Ddim、Dm、D 或 Daug，而不是切换为某种小调音阶。右手配器可以独立开启；四指色彩配器中，大和弦变为属七、小和弦变为减七、减和弦使用减七、增和弦使用增属七；这些变化可能包含调外音。三/七和弦按钮恢复固定配器。试听不识别手势，保留上次已确认的和声设置并明确显示固定状态，左腕与右手配器的手势开关暂时禁用。右腕音色滑杆仍可手动拖动，它控制同一条音色链路。

侧倾指手掌朝向镜头、在画面里左右歪手，不是向前后翻掌。摄像头真实宽高用于还原侧倾角度；左腕分界约为−30°、−10°、+25°，每个分界有约3°防抖缓冲与140ms确认，右腕各侧约30°覆盖全部暗亮范围。右腕回中恢复原色，左腕回中恢复大和弦。右腕滑杆在镜头演奏中是实时只读指示，不受预设切换覆盖。

手掌朝向镜头，双手不要重叠，并使用均匀正面光。无名指与小指存在自然联动，实际演奏的手型稳定性仍需排练。

## 声音设计

两种模式各有三套声音，切换时保留和弦、声部与设备连接：

| 音色 | Ambient | Vocoder |
| --- | --- | --- |
| 月面合唱 | 约620ms慢起、元音合唱、持续漂移 | 快速跟随人声起音的持续合唱、柔和元音 |
| 玻璃花园 | 玻璃敲击、非整数泛音、自然衰减 | 明亮持续人声和弦，叠加音节敲击，长音保持 |
| 暖流簧风 | 约9ms快起、簧片风琴、干燥持续声 | 紧凑簧片载波、较直接的音节响应 |

每个预设的声音身份实际传给 Faust。明亮度、空间和新增的“质感”只是调节它，调整旋钮不会取消身份；右腕使用独立 `wristTone` 音色处理，明亮度旋钮保留预设底色。旧版±25个百分点的亮度偏移已替换，因为它主要扫过能量很少的高频，听感过弱。点击同一和弦或再次按数字键可重奏玻璃的起音，持续手势帧不会反复敲击。

点击 **同一和弦对比** 可比较六段11.8秒样本：同一段和弦、同一旋钮与音量设置，Vocoder 使用同一段合成元音，并非真人录音。每次只播一段；弹窗期间实时乐器静音，关闭后恢复。具体结构、可复验指标及边界见 [声音设计](docs/sound-design.md)。

Vocoder 的 **只用麦克风试音** 可直接连接麦克风，用屏幕固定和弦检查声音，无需摄像头。已连接的麦克风会在切换手势演奏/固定和弦时保留；Esc 才结束整个会话。手势演奏仍要求有效双手姿势，无手或模型未就绪时会明确提示等待，可主动切回固定和弦试音。

**麦克风增益**默认 +12 dB，可在 0–24 dB 调整，输入表按增益后的实际分贝电平显示。轻声偏弱时提高增益；如提示原始输入过载，先降低设备输入音量。增益后的过载则调低网页增益。它不会打开原声直通，也不会给静音输入添加合成信号。

手势识别显示资源下载进度；识别引擎和模型并行下载，长时间停顿时自动重试一次。取消摄像头会同时取消下载；同一页面中完成下载的资源可供重新启动复用。首次加载仍受网络速度影响。

Ambient 是合成伴奏，自然歌声独立。Vocoder 用麦克风16频段包络调制和弦载波；连接麦克风后关闭合成试听源。麦克风原声不直通；它不是保留歌手音色的变调和声器。输出含软限幅与压缩。

## 工程结构

```text
src/main.ts                 页面与演奏会话、权限、快捷键
src/style.css               响应式界面
src/visual.ts               与声部和输出电平关联的粒子轨迹
src/harmony.ts              调性、和弦音与边界迟滞
src/vision/hand-tracker.ts   MediaPipe 摄像头推理、生命周期
src/vision/gesture.ts        关节几何与五指伸展读取
src/vision/twohand.ts        双手角色、完整和弦指型与防抖
src/audio/AudioEngine.ts    Web Audio、麦克风、设备释放
src/audio/chora.dsp          三种音色与16频段Vocoder的Faust源码
src/audio/presets.ts         乐器身份、说明与旋钮默认值
public/audio/               编译后的 DSP 与静态 AudioWorklet
scripts/setup-assets.mjs     手势模型与识别运行库准备
scripts/setup-audio-assets.mjs  Faust 编译与真实 DSP 渲染检查
```

修改 Faust 源码后运行 `npm run audio:compile`。静态 `chora-worklet.js` 避免生产打包改变 Faust 动态生成工作线程的类名。浏览器只下载编译后的 DSP，不下载 Faust 编译器。打包与检查：

```bash
npm test
npm run audio:compile
npm run build
npm run preview
```

生产产物在 `dist/`，可由普通静态服务器托管。实际摄像头与麦克风需要 **HTTPS 或 localhost**；不要直接双击 `index.html`，也不要把非 HTTPS 的局域网地址当成可用演出入口。此次交付没有发布到外网。
